## Projects

### 1. [GlobalConnect](./GlobalConnect)
**Professional Networking Platform**

A full-stack MERN application enabling users to connect, share updates, chat in real-time, and discover job opportunities.

| Layer | Technologies |
|-------|-------------|
| **Frontend** | React 18, Vite, Redux Toolkit, Tailwind CSS v3.4, Socket.io Client |
| **Backend** | Node.js 20.x, Express.js, MongoDB 7.0, Mongoose, JWT, Google OAuth |
| **Real-time** | Socket.io (chat, notifications, typing indicators) |
| **Cloud** | Cloudinary (media), Brevo (email) |
| **DevOps** | Docker, GitHub Actions CI/CD, Vercel, Render |

**Key Features:**
- User authentication (Email/Password + Google OAuth)
- Profile management with experience, education, and skills
- Connection system with request workflow
- Post feed with media upload, likes, and comments
- Real-time chat messaging with typing indicators
- Job board with search, filters, and AI-ready recommendations
- Admin panel for content moderation
- Responsive design across all devices
